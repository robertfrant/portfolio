DulApp

O garderobă digitală pe telefon. Îți fotografiezi hainele, le organizezi pe categorii și combini piese ca să-ți creezi outfit-ul zilei, fără să mai scotocești prin dulap.

  • Cont personal cu înregistrare și autentificare pe email, plus avatar generat automat din inițiale.
  • Adaugă haine: fotografie din galerie, categorie (tricou, pantaloni, adidași), brand și detalii, cum ar fi locul unde se află piesa.
  • Creator de outfit: atingi un slot, alegi piesa din garderobă și se afișează pe ecranul principal.
  • Căutare după categorie sau brand, într-o grilă cu pull-to-refresh.
  • Profil cu toate articolele tale, ștergere cu confirmare și delogare.
  • React Native
  • Expo SDK 53
  • Expo Router
  • TypeScript
  • NativeWind / Tailwind
  • Appwrite
Detalii tehnice
  • Navigare file-based cu expo-router: grupuri (auth) și (tabs), cu rute tipizate.
  • Backend Appwrite: Auth pentru sesiuni, Databases pentru utilizatori și articole, Storage pentru fotografii.
  • Stare globală (utilizator, sesiune, imagine selectată) printr-un React Context.
  • Hook propriu useAppwrite pentru încărcarea datelor și refetch.
  • Stilizare cu NativeWind (clase Tailwind în React Native) și fontul Poppins.

Aplicație de salarizare

O aplicație web prin care o firmă își gestionează angajații și calculează automat salariile: de la salariul de bază și sporuri până la contribuții, impozit și suma virată pe card.

  • Gestiune angajați: adăugare, actualizare și ștergere, cu validări pe fiecare câmp (obligatoriu, interval, format).
  • Calcul automat al salariilor prin proceduri stocate în Oracle, refăcut la orice modificare de date.
  • Procente configurabile pentru CAS, CASS și impozit, cu acces protejat prin parolă.
  • Rapoarte Crystal Reports: stat de plată cu totaluri și fluturași de salariu pentru toți angajații sau pentru unul anume, cu export PDF.
  • Banner dinamic cu AJAX (UpdatePanel + Timer) care se actualizează fără reîncărcarea paginii.
  • C#
  • ASP.NET Web Forms
  • .NET Framework 4.7.2
  • Oracle / PL-SQL
  • Crystal Reports
  • Bootstrap 5
Detalii tehnice
  • Pagini construite pe un Site.Master comun, cu meniu pe categorii: introducere date, tipărire, procente.
  • Acces la date cu SqlDataSource legat de GridView, DetailsView și FormView, cu interogări parametrizate.
  • Logica de calcul în proceduri stocate Oracle (UPDATE_PROCENTE, RECALCULEAZA_SALARII), apelate din C#.
  • Validare cu RequiredFieldValidator, RangeValidator și RegularExpressionValidator.
  • Rapoarte .rpt încărcate dinamic cu ReportDocument, filtrate după criteriile utilizatorului.
