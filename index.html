DulApp

O garderobă digitală pe telefon. Îți fotografiezi hainele, le organizezi pe categorii și combini piese ca să-ți creezi outfit-ul zilei, fără să mai scotocești prin dulap.

  • Cont personal cu înregistrare și autentificare pe email, plus avatar generat automat din inițiale.
  • Adaugă haine: fotografie din galerie, categorie (tricou, pantaloni, adidași), brand și detalii, cum ar fi locul unde se află piesa.
  • Creator de outfit: atingi un slot, alegi piesa din garderobă și se afișează pe ecranul principal.
  • Căutare după categorie sau brand, într-o grilă cu pull-to-refresh.
  • Profil cu toate articolele tale, ștergere cu confirmare și delogare.
  • React Native
  • Expo SDK 53
  • Expo Router
  • TypeScript
  • NativeWind / Tailwind
  • Appwrite
Detalii tehnice
  • Navigare file-based cu expo-router: grupuri (auth) și (tabs), cu rute tipizate.
  • Backend Appwrite: Auth pentru sesiuni, Databases pentru utilizatori și articole, Storage pentru fotografii.
  • Stare globală (utilizator, sesiune, imagine selectată) printr-un React Context.
  • Hook propriu useAppwrite pentru încărcarea datelor și refetch.
  • Stilizare cu NativeWind (clase Tailwind în React Native) și fontul Poppins.
